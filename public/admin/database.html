Migration to MySQL

Use the included scripts/migrate-sqlite-to-mysql.js utility to copy records into an empty MySQL database. It leaves the SQLite source unchanged and stops if target tables contain rows. The current application still runs on SQLite; switching the live app to MySQL requires a separate adapter/configuration change.

Before migrating, stop writes, make a backup, set the MySQL connection variables in .env, run npm run migrate:mysql, compare row counts, and test on a staging copy.
